ClawModeler Rural Demo Fixture
==============================

This fixture mirrors the sample data generated by `clawmodeler-engine sample`.
It is intentionally small so the desktop app and sidecar can exercise the
screening workflow without external GIS, GTFS, or OSM downloads.

Use the desktop "Load Sample Data" action for the packaged path. For manual
engine checks, use:

```sh
clawmodeler-engine workflow full \
  --workspace /tmp/clawmodeler-workbench \
  --inputs \
    assets/fixtures/clawmodeler/rural-demo/zones.geojson \
    assets/fixtures/clawmodeler/rural-demo/socio.csv \
    assets/fixtures/clawmodeler/rural-demo/projects.csv \
    assets/fixtures/clawmodeler/rural-demo/network_edges.csv \
  --question assets/fixtures/clawmodeler/rural-demo/question.json \
  --run-id demo \
  --scenarios baseline infill-growth \
  --skip-bridges
```

The generated sample command also includes a tiny GTFS zip. This checked-in
fixture keeps GTFS text files under `gtfs/` for reviewability.
